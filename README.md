CampusBot AI – Smart College Query Assistant

An AI-powered chatbot designed to simplify campus life by answering common college-related queries instantly.
CampusBot helps students access timetables, syllabus information, events, announcements, and academic resources through an interactive chatbot interface.
 

🚀 Problem Statement
AI Chatbot for College Queries

Students repeatedly ask the same academic and campus-related questions such as:

📅 Timetable details
📚 Syllabus information
🎉 Campus events
🏫 College announcements
📝 Exam schedules
💳 Fee deadlines

CampusBot solves this problem by providing an intelligent AI-based assistant that delivers quick and accurate responses using predefined datasets and APIs.
